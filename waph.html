Labs Overview

Lab 0: Development Environment Setup

In this lab, I installed an Ubuntu 22.04 virtual machine and various software that will be used in this class.

I also cloned the class's repository to my virtual machine and created a private repository for this class.


Lab 1: Foundations of the Web

In this lab I used wireshark to examine HTTP requests and responses and to compare packets from the browser and from telnet.

I wrote a basic CGI program, and a CGI program that used HTML to format the page.

I then wrote a couple basic PHP programs, the second of which I used to demonstrate using curl to make POST requests.


Lab 2: Front-end Web Development

In this lab, I created a basic webpage that used HTML, CSS, and JavaScript.

It needed to use Ajax to make GET and POST requests without reloading the page,

use API calls to display a random joke and guess the user's age based on their name, and use both local and remote JavaScript functions.
