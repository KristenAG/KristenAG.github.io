Class Overview

Dr. Phung's Web Application Programming and Hacking course teaches students how to code web applications with a security-first mindset. We are taught how to hack websites in order to better understand why we need to put security measures in place.


Labs Overview

Lab 0: Development Environment Setup

In this lab, I installed an Ubuntu 22.04 virtual machine and various software that will be used in this class. I also cloned the class's repository to my virtual machine and created a private repository for this class.


Lab 1: Foundations of the Web

In this lab I used wireshark to examine HTTP requests and responses and to compare packets from the browser and from telnet. I wrote a basic CGI program, and a CGI program that used HTML to format the page. I then wrote a couple basic PHP programs, the second of which I used to demonstrate using curl to make POST requests.


Lab 2: Front-end Web Development

In this lab, I created a basic webpage that used HTML, CSS, and JavaScript. It needed to use Ajax to make GET and POST requests without reloading the page, use API calls to display a random joke and guess the user's age based on their name, and use both local and remote JavaScript functions.


Hackathons Overview

Hackathon 1: Cross-site Scripting Attacks and Defenses

This hackathon's purpose was to teach us about various ways a hacker could use cross-side scripting (XSS) to hack a website, and to then use what we learned to improve the code we'd written in Labs 1 and 2.


Projects Overview

Individual Project 1: Front-end Web Development

This project expands upon the topics covered in labs 1 and 2 with the creation of a personal website intended to be a professional profile. The website includes the use of several tools and techniques covered in labs 1 and 2 as well as some I must learn through self-study.
